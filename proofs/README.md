# Formal Proofs — Planned

This directory will hold selective Lean models and proofs for propositions whose risk and value justify formal treatment.

Every proof package must state:

- the natural-language proposition;
- assumptions and excluded conditions;
- the formal model;
- the machine-checked proof;
- the correspondence argument to the Rust implementation;
- limitations and residual risk.

Proof is not a decorative badge and must not be generalized beyond its declared scope.
