# Дорожная карта

## Фаза 0 — Концептуальный фундамент

**Состояние:** завершена как исходная гипотеза.

Результат: миссия, философское направление, модель графа знаний, человекоцентричные законы, независимые уровни верификации, управляемая рекурсивная эволюция и Rust как основной промышленный язык.

## Фаза 1 — Канонический Foundation v0.1

**Состояние:** выполняется.

Результаты: манифест, Конституция, контракт агентов, машинный манифест проекта, метамодель, жизненный цикл, правила верификации, политика доказательности, шаблоны, RFC-процесс, языковая политика и решение о лицензии.

Ворота: артефакты взаимно согласованы, основной маршрут доступен на EN и RU, а метаданные могут быть разобраны первым прототипом верификатора.

## Фаза 2 — Engineering IR и MVP Rust-верификатора

Результаты: Rust workspace, парсер Markdown/YAML, проверка JSON Schema, реестр артефактов, типизированный граф, основные структурные правила, текстовый и JSON-отчёты, сгенерированный Mermaid-граф и первоначальные проверки локализации.

Ворота: верификатор правильно принимает минимальный корректный проект и отклоняет подготовленные некорректные фикстуры.

## Фаза 3 — Вертикальный срез RoadCore

Результаты: артефакты Working Backwards, DDD-модель, спецификация, контракты, модель типов, архитектура, реализация Rust, тесты, семантический аудит и одно выборочное доказательство Lean.

Ворота: путь прослеживаемости проходим от пользовательского обещания до исполняемого свидетельства и обратно.

## Фаза 4 — Опыт начинающего пользователя

Результаты: управляемый инициализатор проекта, навигатор этапов, контекстный компас, видимая карта прогресса, реестр неопределённостей, объясняющая обратная связь и простой стартовый пример графического редактора.

Ворота: незнакомый человек без опыта программирования завершает концепцию небольшого продукта без помощи авторов и способен объяснить каждый этап.

## Фаза 5 — SDK и адаптеры агентов

Результаты: стабильный Rust SDK, JSON-протокол, plugin API, руководство для ChatGPT/Codex, интеграция Claude Code, GitHub Action, интеграция с редакторами и вендорно-независимые пакеты контекста.

Ворота: независимые клиенты используют одну Engineering IR, не дублируя каноническое знание.

## Фаза 6 — Логические и доказательные расширения

Результаты: эксперимент подключаемого rule engine, возможный адаптер SWI-Prolog, экспорт в Lean и пакеты доказательств, исследование законов композиции на основе теории категорий.

Ворота: каждое расширение показывает реальный класс ошибок, который оно обнаруживает лучше детерминированного Rust-ядра, и не становится обязательной сложностью без доказательств.

## Фаза 7 — Масштаб сообщества

Результаты: управление, политика совместимости, миграции, локализация, подписанные релизы, модель безопасности, политика телеметрии, публичные примеры, доказательные досье, обучение участников и модель устойчивого развития.

Ворота: большое сообщество может принимать, обновлять и расширять AXIOPRA без зависимости от первоначальных авторов.

## Текущий следующий шаг

Завершить Foundation v0.1, принять языковую и лицензионную политику, затем специфицировать минимальный Rust-верификатор до написания его реализации. Следующий verifier-spec создаётся сразу на английском и русском языках.
